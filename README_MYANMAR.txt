Number List Keyboard (Android project)

ပါဝင်သည်
- 1 2 3 4 5 6 7 8 9 0 R =
- Backspace, Enter, Copy, Space, Hide
- စာရင်းများကို အများကြီးရေးပြီး နောက်ဆုံး Copy နှိပ်နိုင်သည်။
- Copy က လက်ရှိစာသားနှင့် Total ကို clipboard ထဲ ကူးပေးသည်။
- R/r ကို အတူတူသတ်မှတ်ထားသည်။
- ဥပမာ 12=R500 ကို 1000 ဟုတွက်သည်။
- ဥပမာ 12=1000R500 ကို 1500 ဟုတွက်သည်။
- အပူးစုံ=100 ကို 1000 ဟုတွက်သည်။

APK တည်ဆောက်ရန်
1. ZIP ကို ကွန်ပျူတာမှာ ဖြည်ပါ။
2. Android Studio ဖြင့် NumberListKeyboard ဖိုလ်ဒါကို Open လုပ်ပါ။
3. Gradle sync ပြီး Build > Build APK(s) ကိုရွေးပါ။
4. APK ကို ဖုန်းသို့ပို့ပြီး install လုပ်ပါ။
5. App ကိုဖွင့် > Enable keyboard > Number List Keyboard ကိုဖွင့်ပါ။
6. Choose keyboard ကိုနှိပ်ပြီး Number List Keyboard ကိုရွေးပါ။

မှတ်ချက်
ဒီဖိုင်က Android Studio project source ဖြစ်ပြီး ကြိုတင်တည်ဆောက်ပြီးသား APK မဟုတ်ပါ။
